
Usage: markserv-marker <file-or-directory> [options]
       markserv-marker <command> [options]

Registers the file with the local markserv-marker daemon (starting it if
needed) and prints its preview URL. One daemon serves every registered
file, so there are no port conflicts to check.

Commands
  daemon              run the daemon in the foreground (shows logs)
  stop                stop the running daemon
  status | list       show daemon health and registered files

Options
  -p, --port          daemon port                            [default: 7642]
  -a, --address       daemon address                    [default: localhost]
  -b, --browser       open the browser after registering      [default: on]
      --no-browser    do not open the browser
      --json          print one machine-readable JSON object and exit
  -l, --hotreload     live-reload pages on file change        [default: on]
      --no-hotreload  disable live reload
      --theme         theme: dark | light | synthwave | solarized
      --light         shortcut for --theme light
      --synthwave     shortcut for --theme synthwave
  -s, --silent        no output (daemon)
  -v, --verbose       verbose request logging (daemon)

Examples
  $ markserv-marker README.md
  $ markserv-marker README.md --json
  $ markserv-marker stop

Comments API (for agents)
  GET  /api/files                          list registered files
  GET  /api/files/:id/comments?resolved=false
  POST /api/files/:id/comments             {"line": 12, "body": "...", "author": "claude"}
  PATCH /api/comments/:id                  {"resolved": true}
